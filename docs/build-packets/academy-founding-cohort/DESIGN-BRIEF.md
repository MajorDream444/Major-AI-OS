# UI/UX Design Brief

Apply [Academy visual decisions](https://github.com/MajorDream444/MAIM-Academy---brand/blob/main/handoffs/FOUNDER_DECISIONS_2026-11-01.md) to enrollment, onboarding, schedule, lesson, submission, feedback and progress screens. Use Academy square corners, gold primary actions, Archivo with JetBrains Mono labels, and the approved marks and templates. Link exact design references and approved copy for AFC-01 through AFC-05 in the release review.

Review mobile and desktop, keyboard focus, readable state messages and layout at text zoom. Show clear states for application pending, checkout unavailable, expired invite, payment pending, access granted, private submission, revision requested, accepted and expired access. Show pending destinations as visibly inactive. Keep preview controls and internal notes out of learner views. Design approval and hosted operational readiness have separate evidence.
