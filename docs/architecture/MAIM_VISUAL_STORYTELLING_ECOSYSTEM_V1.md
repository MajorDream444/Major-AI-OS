## Human-first teaching
People may resist new tools when confused, stressed, or overwhelmed. Do not label this self-sabotage or assert a clinical nervous-system mechanism without evidence. Reduce cognitive load; create early wins and permission to begin. The ABCs of AI Mindset are the accessible entry point: Beginner = Notice, Medium = Build, Expert = Design. Core belief: “If you can text, you can use AI.” Tagline: “Likkle by likkle, we build the future.”

## Architecture — separate domains, explicit links
1. Doctrine: 10 Pillars, wider 30-Pillar Life/Money/Technology curriculum, founder philosophy, STB/Build While You Heal lessons.
2. Story: original visual seed, symbolic reading, founder lived experience, character narrative.
3. Learning: ABC entry point, micro-books, e-books, workbooks, courses, quests and measurable wins.
4. Community: cohorts, accountability, recognition, participation.
5. Collectibles: badges, cards, limited-edition art, optional NFTs and physical artifacts. Collectible ownership and rights must be clearly specified.
6. Mystery layer: opt-in clues, discoveries, puzzle fragments, and a possible three-year Captain Lucky global treasure hunt; keep the rules, rewards, safety, accessibility, and eligibility transparent even when the story contains secrets.
7. Agent layer: distinct AI personalities and backstories may be inspired by narrative worlds, with clear distinction between fiction and actual deployed capabilities.
8. Distribution: Substack, YouTube, podcasts, Instagram/Meta, website and owned email.
9. Infrastructure: GitHub versioned source of truth; Airtable metadata and status; Drive final media; Notion editorial/reference mirror; Hanzo as infrastructure layer; owned Vercel + Stripe + Resend for MAIM commerce. Gumroad, Shopify and Kit are retired per the 2026-10-15 directive.

## Editorial production path
Visual seed → founder voice/story → doctrine and fact check → five-minute win → manuscript → creative derivatives → human approval → metadata → export → publication → community feedback → later drops.
Every visual can generate multiple assets, but the 1:12 ratio is a planning hypothesis, not a required quota.

## Proposed progression
Awareness → Belief → First Win → Repeatable Practice → Community Quest → Earned Recognition → Optional Collectible → Advanced Discovery → Mastery → Legacy.
Reward participation and learning, not speculative token appreciation or artificial scarcity. Do not gate core education behind NFTs.
