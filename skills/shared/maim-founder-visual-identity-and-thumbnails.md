## Mandatory production protocol
1. Retrieve this skill and **actual originals** from File Library before generating or editing founder imagery. Never rely on a text-only description if originals are accessible.
2. Use supplied founder photo(s) as identity anchor; preserve recognizable face and age, natural expression, skin tone and characteristic details. Never imply an invented AI portrait is an exact documentary photo.
3. Use the actual provided MD emblem, **exactly once per image**. Do not redraw, replace, repeat, or invent a near-match when the original is available. Avoid using the logo source image's explanatory caption as part of the emblem crop.
4. Keep visual hierarchy mobile-legible. YouTube 16:9 1280x720 or better; safe margins; 3–7 word hero headline preferred; supporting text short; minimize excessive text.
5. Distinguish between *concept image*, *final standalone export*, *founder-approved design*, and *uploaded live thumbnail*. Do not claim publication without successful tool confirmation.
6. When user requests options, create two **separate standalone assets**, not a single split-screen collage, unless comparison sheet is explicitly requested.
7. Evaluate contrast, face authenticity, text spelling, emblem count, mobile readability, and crop. Optional vidIQ thumbnail score is directional only.
8. Preserve original source images; never overwrite them. Archive final with video ID, date, source links, revision, approval and output resolution.
9. Require explicit user selection of final image and destination video before updating YouTube thumbnail.
10. Record which design choices performed well; iterate V2/V3 using YouTube retention/CTR when available rather than assuming a design wins.
